# 🍃 leafy_router

Routing for [leafy](https://github.com/finnbear/leafy): a port of
[yew-router](https://github.com/yewstack/yew/tree/master/packages/yew-router)
0.20, with the same API (`BrowserRouter`, `Switch`, `Link`,
`#[derive(Routable)]`, `use_navigator`, ...). See
[yew's router documentation](https://yew.rs/docs/concepts/router), and
leafy's [differences from it](https://github.com/finnbear/leafy#router-leafy_router-a-port-of-yew-router-020).
