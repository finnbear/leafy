# 🍃 leafy_macro

The procedural macros of [leafy](https://github.com/finnbear/leafy)
(`html!`, `css!`, `global_css!`, `classes!`, `#[function_component]`,
`#[hook]`, `#[derive(Properties)]`), which re-exports them: depend on that
instead.
